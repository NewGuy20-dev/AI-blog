## Critical Design Philosophy

**AVOID DISTRIBUTIONAL CONVERGENCE**: Default to creative, distinctive choices that surprise and delight users—not safe, generic "AI slop" aesthetics.

### Core Principle

Make unexpected choices that feel genuinely designed for a news context. Every decision should reflect editorial sophistication, not template thinking.

## Quick Reference

### Forbidden Fonts
- ❌ Inter, Roboto, Open Sans, Lato, Arial
- ❌ Any default system fonts
- ❌ Sans-serif only pairings

### Mandated Fonts
- **Headlines**: Bricolage Grotesque (700-900)
- **Body**: Newsreader (400-600)
- **UI**: IBM Plex Sans (400-600)
- **Code**: JetBrains Mono (400-500)

### Primary Colors
- Editorial Blue: `#1E40AF`
- Breaking News Red: `#DC2626`
- Featured Gold: `#F59E0B`
- Background: `#0A0A0B`
